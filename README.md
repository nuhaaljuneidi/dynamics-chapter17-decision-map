# Chapter 17: Planar Kinematics of Rigid Bodies Decision Map

An interactive decision map for selecting a solution method for rigid-body kinematics problems from Bedford and Fowler's *Engineering Mechanics: Dynamics*, Chapter 17.

Developed by **Dr. Nuha Aljuneidi** for engineering education and independent study.

## Learning purpose

The map helps students classify a rigid body's motion (translation, rotation about a fixed axis, or general plane motion) and choose the right tool: relative velocity, the instantaneous center, relative acceleration, sliding contacts, or moving reference frames.

## Use locally

Open `index.html` in a modern browser. The tool uses plain HTML, CSS, and JavaScript and requires no build process.
